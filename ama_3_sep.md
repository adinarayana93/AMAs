# AMA - 3 Sep

## 1. Which command is used to find the PID of a particular process?

Use `pgrep <process_name>` or `ps -C <process_name> -o pid` to find the PID of a process.

## 2. What is the `!important` keyword in CSS, and why is it used?

`!important` gives a CSS declaration higher priority than normal declarations. It is used when a style must override other conflicting styles.

## 3. What is the difference between a background image and an `<img>` element in HTML?

- Background image: Used mainly for decoration through CSS.
- `<img>`: Used to display an image as HTML content.

## 4. What happens when a constructor is called?

A constructor is called when an object is created. It initializes the object's attributes and performs the required setup.

## 5. Which HTML tag was traditionally used to create scrolling text?

The `<marquee>` tag was traditionally used for scrolling text.

## 6. What is the difference between `OFFSET` and `LIMIT` in SQL?

- `LIMIT`: Restricts the number of rows returned.
- `OFFSET`: Skips a specified number of rows before returning results.

## 7. What happens when we use `justify-content: space-between` in CSS?

It places the first item at the start, the last item at the end, and distributes the remaining space evenly between the items.

## 8. What is the difference between Flexbox and CSS Grid?

- Flexbox: Mainly for one-dimensional layouts, either a row or a column.
- Grid: Mainly for two-dimensional layouts, rows and columns.

## 9. What is the difference between `DELETE`, `DROP`, and `TRUNCATE` in SQL?

- `DELETE`: Removes selected rows from a table.
- `TRUNCATE`: Removes all rows from a table.
- `DROP`: Removes the table or database itself.

## 10. What is a `LEFT JOIN` in SQL?

A `LEFT JOIN` returns all rows from the left table and matching rows from the right table. If there is no match, the right-side columns contain `NULL`.

## 11. What is a subquery in SQL, and what are its different types?

A subquery is a query written inside another query.

Common types:
- Scalar subquery
- Single-row subquery
- Multi-row subquery
- Correlated subquery

## 12. What are the attributes of a link tag?

Common `<a>` tag attributes include:

- `href` — specifies the destination.
- `target` — specifies where to open the link.
- `rel` — defines the relationship with the linked resource.
- `download` — indicates that the linked resource should be downloaded.
