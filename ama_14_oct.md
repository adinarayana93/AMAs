# AMA - 14 Oct

## 1. What is a context window?

A context window is the amount of text and information Claude can consider in one conversation at a time.

## 2. What is compaction?

Compaction summarizes earlier conversation details to make room for more context.

## 3. What are tools?

Tools let Claude perform actions, such as searching the web, running code, or working with connected services.

## 4. What are Skills?

Skills are reusable instructions and resources that help Claude perform specific tasks consistently.

## 5. What is a project in Claude?

A Project is a workspace where you can keep related chats, instructions, and reference files together.

## 6. What is MCP?

MCP (Model Context Protocol) is a standard that lets AI assistants connect to external tools and data sources.
