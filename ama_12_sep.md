# AMA - 12 Sep

## What is JavaScript?

JavaScript is a programming language mainly used to make web pages interactive and dynamic.

## What is dynamic typing in JavaScript?

Dynamic typing means a variable can hold different types of values without declaring its type.

## What is a higher-order function?

A higher-order function is a function that takes another function as an argument or returns a function.

## Which CLI command is used to check the username?

The `whoami` command is used to check the current username.

## What is the TDZ (Temporal Dead Zone) in JavaScript?

TDZ is the period from the start of a block until a `let` or `const` variable is declared, where accessing it causes an error.

## How do you check the tables present in a database?

In PostgreSQL, use the `\dt` command to list the tables.

## What is the `filter()` function?

`filter()` creates a new array containing the elements that satisfy a given condition.

## What is hoisting in JavaScript?

Hoisting is JavaScript's behavior of processing declarations before executing the code.

## What is encapsulation?

Encapsulation means keeping data and the methods that work on it together and controlling direct access to the data.

## What is the difference between `let`, `const`, and `var`?

- `let`: block-scoped and can be reassigned.
- `const`: block-scoped and cannot be reassigned.
- `var`: function-scoped and can be redeclared.

## How do you declare and initialize a Set in JavaScript?

```javascript
const numbers = new Set([1, 2, 3]);
```

## What is a closure in JavaScript?

A closure is a function that remembers and can access variables from its outer scope even after the outer function finishes.

## What are some examples of higher-order functions?

Examples include `map()`, `filter()`, `reduce()`, and `forEach()`.
