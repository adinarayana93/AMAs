# AMA - 25 Sep

## What is the event loop?

The event loop allows JavaScript to handle asynchronous tasks by checking the call stack and task queue.

## What is hoisting?

Hoisting is JavaScript's behavior of processing declarations before executing the code.

## What are status codes?

Status codes are HTTP response codes that tell whether a request was successful or failed.

## What is constructor overloading?

Constructor overloading means having multiple constructors with different parameters. JavaScript does not support it directly.

## What is the difference between `forEach()` and `map()`?

- `forEach()` runs a function for each element but does not return a new array.
- `map()` returns a new array with transformed elements.

## What is a promise?

A Promise is an object that represents the future result of an asynchronous operation.

## What is a REST API?

A REST API is an API that uses HTTP methods like GET, POST, PUT, and DELETE to work with resources.

## When do we use `JSON.parse()`?

We use `JSON.parse()` to convert a JSON string into a JavaScript object.

## What is event listening?

Event listening means waiting for an event and running a function when that event occurs.

## What is a web application?

A web application is software that runs through a web browser and allows users to interact with it.

## What is callback hell?

Callback hell is deeply nested callbacks that make asynchronous code difficult to read and maintain.

## What is the difference between `null` and `undefined`?

- `undefined` means a value has not been assigned.
- `null` is an intentional empty value.

## What is the difference between `className` and `classList` in the DOM?

- `className` gets or sets the complete class attribute as a string.
- `classList` provides methods to add, remove, toggle, and check individual classes.
